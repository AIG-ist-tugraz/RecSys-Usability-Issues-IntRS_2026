# Detecting Usability Issues in Recommender Systems with Multimodal Large Language Models

This repository contains the experiment artifacts and supplementary material for the paper **"Detecting Usability Issues in Recommender Systems with Multimodal Large Language Models"** presented at **IntRS 2026**.

## Project Overview

This project explores the capability of Multimodal Large Language Models (MLLMs) to identify usability issues in Recommender Systems (RecSys) by analyzing screen recordings of user interfaces.

## Repository Structure

The repository is organized as follows:

- `prompts/`: Contains the prompts used for the MLLM evaluation.
  - `system_prompt.py`: Defines the role and general guidelines for the MLLM as a usability expert.
  - `usability_analysis.py`: Contains the template for the evaluation prompt, including the specific usability criterion to be tested.
- `results/`: Experiment outputs generated by different MLLMs (e.g., Gemini 2.5 Flash, GPT-5.4 Mini), grouped by model. Each file contains the identified usability issues for a specific app recording.
- `usability_criteria/`:
  - `usability_criteria.json`: A set of 11 usability criteria specifically tailored for Recommender Systems, covering general UI, preference elicitation, and recommendation presentation.
- `videos/`: Screen recordings of different Recommender System interfaces used as input for the models:
  - `Deepworkradio.mp4`
  - `Ecobite.mp4`
  - `Pocketquest.mp4`
